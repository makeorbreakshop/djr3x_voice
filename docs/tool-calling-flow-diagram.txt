3. STREAMING RESPONSE PROCESSING
================================================================================

OpenAI API Response Stream:
  data: {"choices":[{"delta":{"content":"I'll play"}}]}
  data: {"choices":[{"delta":{"content":" music"}}]}
  data: {"choices":[{"delta":{"tool_calls":[{"id":"call_123","function":{"name":"play"}}]}}]}
  data: {"choices":[{"delta":{"tool_calls":[{"id":"call_123","function":{"arguments":"{\"track"}}]}}]}
  data: {"choices":[{"delta":{"tool_calls":[{"id":"call_123","function":{"arguments":"\":\"cantina_band"}}]}}]}
  data: {"choices":[{"delta":{"tool_calls":[{"id":"call_123","function":{"arguments":"\""}}]}}]}
  data: {"choices":[{"delta":{"tool_calls":[{"id":"call_123","function":{"arguments":"}"}}]}}]}
  data: [DONE]

                                ↓

┌─────────────────────────────────────────────────────────────────────────┐
│ GPTService._stream_gpt_response(api_url, request_data)                 │
│                                                                         │
│ For each chunk in response.content:                                     │
│   ├─ Extract delta from parsed JSON                                     │
│   │                                                                     │
│   ├─ IF "content" in delta:                                             │
│   │  └─ full_content += delta["content"]                                │
│   │  └─ emit LLM_RESPONSE_CHUNK event                                   │
│   │                                                                     │
│   └─ IF "tool_calls" in delta:                                          │
│      │                                                                  │
│      └─ For each tool_call_delta:                                       │
│         ├─ tool_call_id = tool_call_delta["id"]                         │
│         │                                                               │
│         ├─ IF NOT in tool_calls_collection:                             │
│         │  ├─ Create new entry with empty name + arguments             │
│         │  └─ Add to incomplete_tool_calls set                          │
│         │                                                               │
│         ├─ Append to function["name"]                                   │
│         ├─ Append to function["arguments"]                              │
│         │                                                               │
│         └─ TRY json.loads(arguments):                                    │
│            ├─ SUCCESS → Mark complete, add to complete_tool_calls      │
│            │           → Call _process_tool_calls() immediately        │
│            │                                                            │
│            └─ FAIL (JSONDecodeError):                                   │
│               ├─ IF args end with '}':                                  │
│               │  └─ Replace "'" with '"' and retry                      │
│               │     ├─ SUCCESS → Process immediately                   │
│               │     └─ FAIL → Continue streaming                       │
│               │                                                         │
│               └─ ELSE → Continue streaming next chunk                   │
│                                                                         │
│ After [DONE]:                                                           │
│   └─ Final attempt to process any remaining incomplete_tool_calls      │
│      └─ Log warnings for truly incomplete calls                         │
│                                                                         │
│ Add complete message to memory:                                         │
│   └─ memory.add_message("assistant", full_content, tool_calls=...)     │
│                                                                         │
│ Emit final LLM_RESPONSE event:                                          │
│   └─ await emit(LLM_RESPONSE, LLMResponsePayload(...))                 │
└─────────────────────────────────────────────────────────────────────────┘


4. TOOL CALL PROCESSING (Intent Detection)
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│ GPTService._process_tool_calls(tool_calls, response_text)              │
│                                                                         │
│ For each tool_call in tool_calls:                                       │
│   ├─ Extract:                                                           │
│   │  ├─ function_name = tool_call["function"]["name"]                  │
│   │  └─ function_args_str = tool_call["function"]["arguments"]         │
│   │                                                                     │
│   ├─ Parse arguments:                                                   │
│   │  ├─ TRY: function_args = json.loads(function_args_str)              │
│   │  └─ CATCH JSONDecodeError: log and continue to next tool call      │
│   │                                                                     │
│   ├─ Validate against Pydantic:                                         │
│   │  ├─ model_map = function_name_to_model_map()                        │
│   │  ├─ IF function_name in model_map:                                  │
│   │  │  ├─ param_model = model_map[function_name]                       │
│   │  │  ├─ TRY: validated = param_model(**function_args)                │
│   │  │  │  └─ function_args = validated.model_dump()                   │
│   │  │  └─ CATCH ValidationError: log and continue                      │
│   │  │                                                                  │
│   │  └─ ELSE: log warning, use unvalidated args                         │
│   │                                                                     │
│   └─ Create & emit INTENT_DETECTED event:                               │
│      └─ IntentPayload(                                                  │
│         ├─ intent_name=function_name,  # e.g., "play_music"            │
│         ├─ parameters=function_args,    # {"track": "cantina_band"}    │
│         ├─ original_text=response_text, # Full LLM response            │
│         ├─ conversation_id=...                                          │
│         └─ confidence=None                                              │
│      )                                                                  │
│      └─ await emit(INTENT_DETECTED, payload)                            │
│                                                                         │
│ Log final statistics:                                                   │
│   └─ "Processed X/Y tool calls successfully"                            │
└─────────────────────────────────────────────────────────────────────────┘

10. ERROR HANDLING SCENARIOS
================================================================================

Scenario 1: Invalid JSON in tool arguments
  Tool streaming: arguments = "{\"track\": \"cantina"
  JSON parse attempt: FAIL
  args_str ends with '}': NO
  → Continue streaming, eventually timeout or receive [DONE]
  → _process_tool_calls() skips malformed tool call
  → Emit partial INTENT_EXECUTION_RESULT with error

Scenario 2: Tool handler not registered
  IntentRouterService._handle_intent()
  → intent_name not in self._intent_handlers
  → Log warning
  → Emit INTENT_EXECUTION_RESULT with success=False
  → GPTService generates error feedback

Scenario 3: Tool execution throws exception
  Handler's try/except catches exception
  → Return {"success": False, "error": "..."}
  → INTENT_EXECUTION_RESULT emitted with success=False
  → GPTService generates error feedback

Scenario 4: Parameter validation fails
  ValidationError raised by Pydantic
  → _process_tool_calls() catches and logs error
  → Tool call skipped
  → No INTENT_DETECTED emitted for that call

Scenario 5: API rate limit exceeded
  OpenAI API returns 429 status
  → _stream_gpt_response() logs error
  → _emit_status() called with ERROR status
  → User hears error message from fallback
