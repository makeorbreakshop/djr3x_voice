## Critical Bug Fix

### Audio Playback Error
**Problem**: `NameError: name 'time' is not defined` in ElevenLabs PCM streaming
**Solution**: Added missing `import time` statement in streaming code block
**Impact**: Audio now plays correctly with PCM format

## LED Animation Improvements

### 1. Amplitude Boost for Mouth LEDs
- Initial values too low (M000-M068, only 27% max)
- Added 8x boost multiplier for dramatic effect
- Now reaches full M000-M255 range

### 2. Dynamic Range Enhancements
- **Removed amplitude floor**: Full 0-100% range (was forced 15% minimum)
- **Logarithmic scaling**: Natural loudness perception (-60dB to -10dB)
- **Mode-specific baselines**: ENGAGED = 0%, others = 8%

### 3. ENGAGED Mode Special Effects
- Mouth completely black when silent
- Golden yellow (255, 200, 0) only appears when talking
- Eyes remain cyan while mouth is golden (color swap effect)

### 4. Color Improvements
- IDLE eyes: Changed from (255, 60, 0) red-orange to (255, 120, 0) bright orange
- Added distinct mouth colors per mode:
  - IDLE: Blue mouth
  - ENGAGED: Golden yellow
  - LISTENING: Darker blue
  - THINKING: Purple
