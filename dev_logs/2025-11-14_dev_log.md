## Extended Session - Memory & Voice Recognition

- **SessionMemory**: In-memory conversation history (50 messages, 40K tokens)
- **MemoryService**: Persistent JSON state for DJ mode, preferences, track history
- Current implementation sends full conversation history to Claude each request
- No automatic pruning beyond basic token limits

### 6. Voice Recognition & Diarization Research

- Supports speaker diarization with `diarize: true` parameter
- Returns speaker ID (0, 1, 2...) and confidence per word
- Industry-leading accuracy (53% better than competitors)
